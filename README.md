## Choix des couleurs

Pour mon site DevMeet, j'ai choisi un fond bleu foncé (`bg-slate-950`) pour donner un style moderne et professionnel. J'ai utilisé une couleur légèrement plus claire (`bg-slate-900`) pour les sections et les cartes. Le cyan (`text-cyan-400`) permet de mettre en valeur les titres et les informations importantes. Enfin, le blanc (`text-white`) permet de rendre le texte lisible.

## Organisation de la direction artistique (DA)

Pour organiser ma page, j'ai essayé de suivre les étapes que nous avons vues pendant le cours du mardi 27 octobre 2026. J'ai commencé par structurer le contenu en différentes sections HTML, puis j'ai ajouté les classes Tailwind CSS.

J'ai utilisé ChatGPT comme outil d'aide pendant la réalisation du projet. Il m'a permis de mieux comprendre certaines classes Tailwind CSS que je ne connais pas encore par cœur et de trouver des explications lorsque j'avais des difficultés.
